# FineHall-MT-Dataset

**A Fine-grained Benchmark for Hallucinations in Multilingual LLM Translation**

FineHall-MT is a multilingual benchmark for detecting and diagnosing hallucinations in LLM-generated translations. It contains **70,565 translations** of **1,283 English source texts** into **11 target languages**, generated by **five LLMs**. In addition to hallucination presence, the benchmark provides fine-grained failure categories, semantic severity, and category-specific source- and target-side evidence.

## Dataset Overview

| Property | Details |
|---|---|
| Translations | 70,565 |
| English source texts | 1,283 |
| Target languages | 11 |
| Translation models | 5 |
| Model–language combinations | 55 |
| Hallucination-positive translations | 18,503 |
| Non-hallucinated translations | 52,062 |

**Target languages:** German (de), French (fr), Spanish (es), Portuguese (pt), Russian (ru), Chinese (zh), Japanese (ja), Korean (ko), Bengali (bn), Tamil (ta), and Swahili (sw).

**Translation models:** GPT-5.5, Llama-3.1-8B-Instruct, Qwen3-8B, InternLM3-8B-Instruct, and Mistral-7B-Instruct-v0.3.

**Source collections:** WMT24++, NTREX-128, and two-step-lit-eval.

## Annotation Schema

FineHall-MT distinguishes four hallucination categories:

| Category | Definition | Evidence |
|---|---|---|
| **Instruction Drift** | Output fails to perform the requested translation task. | Task-level label |
| **Unsupported Content** | Translation adds information not supported by the source. | Target-side span |
| **Source Contradiction** | Translation contradicts source-grounded meaning. | Source- and target-side spans |
| **Key Omission** | Translation omits semantically important source content. | Source-side span |

Source-semantic categories may co-occur; a primary category is also recorded. Source-semantic violations are assigned **minor**, **moderate**, or **major** severity, whereas Instruction Drift receives task-level annotation only.

## Data Files

- **`data/finehall_mt.jsonl`** — The full translation corpus with automatically generated fine-grained annotations.
- **`data/human_reference.jsonl`** — The 1,100-instance human-adjudicated evaluation subset (20 examples per model–language combination). 

The data are distributed in **JSON Lines (JSONL)** format, with one translation instance per line.
